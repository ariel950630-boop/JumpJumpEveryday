# 🎮 天天向上跳 (JumpJumpEveryday)

一個使用 Java Swing / AWT 繪製的 2D 垂直計時跳躍遊戲。

## ✨ 遊戲特色
- **動態捲軸地圖**：玩家向上跳躍時畫面自動向下捲動。
- **計時挑戰**：內建 20 秒倒數計時機制。
- **圖片資源繪製**：自訂角色、平台與選單背景圖。
- **隨機平台生成**：演算法動態計算平台產生的合理距離。

## 🛠️ 開發環境與技術
- **Language**: Java 17+
- **GUI Framework**: Java Swing / AWT
- **Resource Handling**: ImageIO, ResourceLoader
